# Scaling Laws

How loss falls predictably with model size, data, and compute — and what that does and
does not let you predict.

## What it covers
Pre-LLM learning curves → Kaplan (2020) and Chinchilla (2022) compute-optimal results →
refinements and data-constrained regimes → architecture/hyperparameter knobs → from loss
to downstream capability → why power laws arise → scaling ladders in practice →
frontier case studies.
