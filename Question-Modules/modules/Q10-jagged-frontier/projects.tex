\begin{enumerate}[leftmargin=1.5em]
\item \textbf{Map a jagged frontier (medium, 4--6 days).} Build a battery of matched easy/hard task pairs; measure a model across them and visualize where competence is non-monotonic in human-perceived difficulty.
\item \textbf{Tokenization repair (small, 2--3 days).} Take a character-counting or arithmetic failure; show it is fixed by reframing the input (spelled-out letters, digit separators) without changing the model.
\item \textbf{Tool-augmentation study (medium, 1 week).} Compare a model alone vs.\ the same model with a calculator/code tool on an arithmetic suite; quantify how much of the ``simple mistake'' gap is closed by the harness.
\end{enumerate}
