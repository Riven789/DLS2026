\documentclass[11pt]{article}\usepackage{../../_shared/dlsmodule}\begin{document}\section*{Understanding check}\textbf{Question.} A team reports 94\% benchmark accuracy for a chatbot. Name two additional artifacts needed before approving deployment and explain what each can reveal.\\[1em]\textbf{Expected answer.} Any two of: representative error analysis/stress suite, data provenance and split documentation, tool-enabled end-to-end test, threat model/permissions review, monitoring and rollback plan. Each must connect an artifact to a failure boundary.\\[1em]\textbf{Misconception diagnosed.} ``A high benchmark score proves the product is ready.''\end{document}
