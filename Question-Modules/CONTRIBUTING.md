# Contribution and review protocol

1. Claim a module in `register/QUESTION_MODULE_REGISTER.csv`; set `author` and the two non-author reviewers.
2. Create the complete artifact set specified in `docs/QUESTION_DRIVEN_MODULE_PROGRAM.md`.
3. Record claim-to-source evidence in `sources.md`; run LaTeX and code checks before requesting review.
4. Both peer reviewers inspect the rendered tutorial and slides. The technical reviewer checks sources/derivations/code; the teaching reviewer checks clarity, activity, rendering, and course-policy fit.
5. The author records revisions and one reviewer independently reruns the relevant build/code check. Only then may a module be marked `ready_for_Rick`.
