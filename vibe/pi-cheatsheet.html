pi — Cheat Sheet

AI coding assistant · CLI, slash commands & hotkeys

CLI — Getting Started

piStart interactive session
pi "msg"Start with a prompt
pi @file.js "fix"Attach file(s) to prompt
pi -p "msg"Non-interactive, print & exit
pi -cContinue previous session
pi -rResume: pick a session
pi -vShow version
pi -hShow help

CLI — Sessions

--session <id>Use specific session file/UUID
--fork <id>Fork session into new one
--no-sessionEphemeral (don't save)
-n <name>Set session display name
--export <f>Export session to HTML

CLI — Models & Thinking

--provider <n>Provider (default google)
--model <pat>Model pattern or ID
--models <p,p>Patterns for Ctrl+P cycling
--thinking <lvl>off/low/medium/high/max
--list-modelsList available models
--api-key <k>API key (else env vars)

CLI — Tools & Extensions

-t <tools>Allowlist of tools to enable
-xt <tools>Denylist of tools to disable
-ntDisable all tools
-e <path>Load an extension
--skill <path>Load a skill
--theme <path>Load a theme
-aTrust project-local files

CLI — Subcommands

pi install <src>Install extension
pi remove <src>Remove extension
pi updateUpdate pi / extensions
pi listList installed extensions
pi configEnable/disable resources
pi auth <cmd>Print credentials

Slash — Sessions

/newStart a new session
/resumePick a previous session
/sessionInfo: file, ID, tokens, cost
/name <n>Set display name
/treeJump to any point, continue
/forkNew session from a message
/cloneDuplicate active branch
/trustSave project trust decision

Slash — Context & Export

/compact [p]Compact context, opt. prompt
/copyCopy last reply to clipboard
/export [f]Export to HTML or JSONL
/import <f>Import & resume from JSONL
/shareUpload as private gist link
/reloadReload config & extensions

Slash — Config

/modelSwitch models
/scoped-modelsModels for Ctrl+P cycling
/settingsThinking, theme, delivery
/login /logoutManage credentials
/hotkeysShow all shortcuts
/changelogVersion history
/quitQuit pi
/skill:nameInvoke a skill

Hotkeys — Application

EscCancel / abort
Ctrl+CClear editor / copy selection
Ctrl+DExit (editor empty)
Ctrl+ZSuspend to background
Ctrl+GOpen external editor
Ctrl+VPaste image from clipboard
EnterSubmit input
Shift+EnterNew line

Hotkeys — Models & View

Ctrl+LOpen model selector
Ctrl+PCycle to next model
Shift+Ctrl+PCycle to previous model
Shift+TabCycle thinking level
Ctrl+TCollapse/expand thinking
Ctrl+OCollapse/expand tool output
Ctrl+XCopy last assistant message

Hotkeys — Queue & Editing

Alt+EnterQueue follow-up message
Alt+UpRestore queued to editor
Ctrl+WDelete word backward
Ctrl+UDelete to line start
Ctrl+KDelete to line end
Ctrl+YYank (paste deleted)
Ctrl+A / Ctrl+ELine start / end
Ctrl+−Undo last edit

Built-in Tools

readRead file contents
bashExecute bash commands
editEdit files (find/replace)
writeWrite / overwrite files
grepSearch contents (off default)
findFind files by glob (off def.)
lsList directory (off default)

Key Env Vars

PI_CODING_AGENT_DIRConfig dir (~/.pi/agent)
..._SESSION_DIRSession storage dir
PI_OFFLINEDisable startup network ops
PI_TELEMETRYToggle install telemetry
EDITOR / VISUALExternal editor (Ctrl+G)
Customize keybindings in ~/.pi/agent/keybindings.json · run /reload to apply · Type / in editor for commands
