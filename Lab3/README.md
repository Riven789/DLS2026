# Lab 3 — Smaller, Faster Neural Networks with Pi

Student-facing assignment files:

- [`lab3.pdf`](lab3.pdf) — complete assignment specification
- [`lab3.tex`](lab3.tex) — editable LaTeX source

The lab uses Pi to implement and run laptop-scale MLP, CNN, and GNN experiments covering four sparsity methods and reduced precision. Students retain responsibility for the experimental design, evidence review, and a one-page implications memo written in their own words.

Release and due dates are posted in the course system.
